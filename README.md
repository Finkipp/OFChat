# Quark

Минималистичный настольный XMPP-клиент для Openfire на GTK 3. Личная переписка,
группы контактов, локальная история SQLite, системные уведомления, трей,
рассылка, запросы внимания XEP-0224 и экспорт TXT/CSV.

## Установка и запуск

RPM для Red OS 8 (x86_64, Python 3.11) доступен в
[GitHub Releases](https://github.com/Finkipp/Quark/releases). После установки
запускайте **Quark** из меню приложений либо командой `quark`.

Для запуска из исходников нужны Python 3.11+, GTK 3, PyGObject, AppIndicator3,
libsecret и GtkSourceView 4:

```sh
sudo dnf install python3-gobject-base gtk3 libappindicator-gtk3 libsecret gtksourceview4
python3 -m venv --system-site-packages .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Можно использовать `python main.py`: при наличии `.venv` приложение перейдёт
на его интерпретатор. В старой рабочей папке каталог исходников может по-прежнему
называться `openfire-chat`.

Введите JID (`имя@домен`), пароль, при необходимости адрес и порт сервера
(обычно 5222). Для самоподписанного TLS-сертификата подтвердите отпечаток SHA-256.
Нажатие на крестик оставляет Quark работающим в системном трее; пункт «Выйти»
завершает приложение и соединение.

## Сообщения

- Вся переписка доступна в главном окне; сначала отображаются последние 100
  сообщений, более ранние загружаются кнопкой сверху. Лупа в заголовке ищет
  по всей истории выбранного контакта (без учёта регистра).
- В текстовом поле Enter отправляет сообщение, Shift+Enter вводит новую строку.
  Поддерживаются `**жирный**`, `*курсив*`, `` `код` ``, ссылки
  `[название](https://example.org)` и блоки с тройными обратными кавычками.
  Язык после открывающих кавычек (`py`, `js`, `sh` и др.) включает подсветку,
  если GtkSourceView распознаёт язык. У блока есть кнопка «Копировать».
  Форматирование доступно также через контекстное меню текстового поля;
  Ctrl+B и Ctrl+I применяются к выделению.
- Состояние исходящего сообщения: `⋯` — ожидается подтверждение, `✓` —
  доставлено, `✓✓` — прочитано, красный `!` — ошибка передачи. Уведомления о
  доставке и чтении зависят от поддержки XEP-0184 и XEP-0333 клиентом
  собеседника. «Печатает», «перестал печатать» и «неактивен» используют XEP-0085.
- Кнопка скрепки отправляет файл до 5 МБ, Ctrl+V вставляет изображение из
  буфера обмена. Передача идёт напрямую между двумя клиентами **Quark** через
  XMPP IBB (XEP-0047); клиент получателя должен быть в сети. Копии файлов
  сохраняются локально и очищаются через сутки при работающем Quark либо при
  следующем запуске после истечения этого срока. Сервер Openfire только
  пересылает блоки: загрузка в серверное файловое хранилище не используется.

Меню заголовка: **Действия → Рассылка** отправляет одинаковое личное сообщение
нескольким контактам; **Файл → Экспорт переписки** сохраняет её в UTF-8 TXT/CSV.
Группы из списка контактов Openfire отображаются в левой панели.

## Данные и вход

При выборе «Сохранить вводимые данные» пароль помещается в системную ключницу
Secret Service (не в JSON); JID и адрес — в `~/.config/quark/account.json`.
Опция автоматического входа создаёт ярлык в `~/.config/autostart/` и включает
сохранение данных. Без доступной ключницы пароль не сохраняется.

Существующая история и ранее подтверждённые сертификаты продолжают храниться
по прежним адресам `~/.local/share/openfire-chat/history.db` и
`~/.config/openfire-chat/certificates.json`. Локальные вложения находятся в
`~/.local/share/openfire-chat/attachments/`. Установка или удаление RPM эти
пользовательские данные не затрагивает.

## Разработка и RPM-релизы

Тесты: `.venv/bin/python -m unittest discover -s tests -v` (для TLS-теста
нужна утилита `openssl`). Пакет собирается из `packaging/quark.spec`.
После изменения `Version` отправка соответствующего тега (`v0.3.0` и т. п.)
запускает GitHub Actions: тесты, сборку и публикацию RPM в Releases.
