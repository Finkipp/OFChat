# OFChat

OFChat — небольшой настольный клиент для личной переписки через Openfire (XMPP)
в GTK/GNOME.

Возможности: список контактов из Openfire, личные сообщения, локальная история
в SQLite, системные уведомления о новых сообщениях и запросах внимания,
счётчики непрочитанных сообщений, цветные статусы контактов (активен,
отошёл, не в сети), кнопка «Обратить внимание» (XEP-0224). Можно открыть чат
с любым JID вручную.

## Запуск (Linux)

Нужны Python 3.11+, GTK 3, PyGObject и AppIndicator3 из пакетов дистрибутива.
В Red OS 8: `sudo dnf install python3-gobject-base gtk3 libappindicator-gtk3`.

```sh
cd OFChat
python3 -m venv --system-site-packages .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python main.py
```

Если `.venv` уже создан и зависимости установлены, из каталога проекта также
работают `python main.py` и `python3 main.py`: запуск автоматически переходит
на Python из `.venv`. В существующей локальной папке проект может по-прежнему
называться `openfire-chat`.

Введите полный JID (`имя@домен-openfire`) и пароль. По умолчанию клиент
подключается к домену JID на порту 5222; если Openfire доступен по другому адресу, заполните
«Адрес сервера» (имя хоста или IP) и порт клиентского XMPP-соединения (обычно
5222). Сервер Openfire должен разрешать подключения клиентов XMPP.

При первом подключении с самоподписанным сертификатом появится окно с адресом
сервера и отпечатком SHA-256. Сверьте отпечаток с сертификатом Openfire и
нажмите «Доверять сертификату». Решение сохраняется для сочетания домена XMPP,
адреса и порта в `~/.config/openfire-chat/certificates.json` (либо в каталоге
`$XDG_CONFIG_HOME/openfire-chat/`). Если сертификат изменится, клиент снова
попросит подтверждение. Сертификаты, уже доверенные системе, принимаются
автоматически. Подключение использует STARTTLS на клиентском порту Openfire.

История каждого аккаунта хранится в
`~/.local/share/openfire-chat/history.db`. Пароль на диск не записывается.
Уведомления используют системную службу уведомлений рабочего стола; для
активации окна нажатием на уведомление при установке RPM создаётся ярлык
автоматически. При работе из исходников можно установить свой ярлык:

```sh
mkdir -p ~/.local/share/applications
cp OFChat.desktop ~/.local/share/applications/org.example.OFChat.desktop
```

После копирования замените `Exec=ofchat` на полный путь к `/usr/bin/python3`
и `main.py` (если RPM ещё не установлен). В этом окружении такой локальный
ярлык уже установлен в `~/.local/share/applications/`.
Для сохранения существующей переписки и принятых сертификатов пользовательские
данные продолжают храниться в каталогах с прежним названием `openfire-chat`.

Крестик окна сворачивает OFChat **в системный трей**, оставляя подключение к
серверу активным. Из меню значка можно вернуть окно или полностью выйти из
программы. Трей должен поддерживаться окружением рабочего стола (StatusNotifier);
при отсутствии AppIndicator используется встроенный системный значок GTK.

Меню заголовка окна:

- **Действия → Рассылка** — выбрать несколько контактов, при необходимости
  добавить JID вручную и отправить им одинаковое личное сообщение;
- **Действия → История** — выбрать собеседника, искать текст и листать
  переписку страницами по 50 сообщений. В главном окне показаны лишь последние
  три дня (не более 100 сообщений);
- **Файл → Экспорт переписки** — сохранить всю переписку с выбранным контактом
  в UTF-8 TXT или CSV;
- **О программе** — версия и разработчики; **Отключиться** — завершить XMPP-сеанс;
  **Выйти из OFChat** — закрыть программу, включая значок в трее.

Проверка без Openfire: `.venv/bin/python -m unittest discover -s tests -v`
(для теста TLS необходима утилита `openssl`).

## RPM-релизы

Пакет для Red OS 8 (x86_64, Python 3.11) собирается из
`packaging/ofchat.spec`. Он содержит Python-зависимости и устанавливает
команду `ofchat` и ярлык приложения; GTK 3 и PyGObject устанавливаются
пакетным менеджером. Исходный код распространяется под лицензией MIT.

GitHub Actions запускает тесты и публикует собранный `.rpm` во вкладке
**Releases** при отправке тега вида `v0.2.0`. Перед новым релизом обновите
`Version` в `packaging/ofchat.spec`, затем создайте и отправьте совпадающий
тег. Пакет устанавливается командой `sudo dnf install ./ofchat-*.rpm`.

Существующие личные данные в `~/.local/share/openfire-chat/` и
`~/.config/openfire-chat/` при установке или удалении RPM не затрагиваются.
